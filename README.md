# VOXELIA Food GLB Pack

This package contains 17 actual `.glb` 3D assets recreated from the FOOD section of the supplied VOXELIA sprite sheet, plus a responsive `index.html` viewer.

## Use
Upload the entire folder to the same GitHub repository. `index.html` loads each file from `models/`.

## Notes
- Catalogue image shows two Jungleplum entries and repeats 4179 for Mango/Coconut. Both are preserved as separate assets; Coconut uses internal key `4179B` to avoid filename collision.
- Models are original low-poly/voxel-style 3D interpretations designed to match the supplied sprites rather than flat image planes.
